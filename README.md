# Cat Search — The Cat API

Application that shows information about a cat breed selected from a list, using The Cat API.

## 🔗 Links

- **Live Demo:** [https://vitalii1408.github.io/goit-js-hw-10/](https://vitalii1408.github.io/goit-js-hw-10/)
- **Source code:** [github.com/vitalii1408/goit-js-hw-10](https://github.com/vitalii1408/goit-js-hw-10)

## 🛠 Tech Stack

- JavaScript (ES6+)
- HTML5
- CSS3
- Vite
- Axios
- The Cat API
- Notiflix

## ✨ Features

- Load the list of breeds into a select
- Show the photo and description of the selected breed
- Loader while data is loading
- Error notification if the request fails

## 🚀 Getting Started

```bash
git clone https://github.com/vitalii1408/goit-js-hw-10.git
cd goit-js-hw-10
npm install
npm run dev
```

Open the local address shown in the terminal (usually [http://localhost:5173](http://localhost:5173)).
